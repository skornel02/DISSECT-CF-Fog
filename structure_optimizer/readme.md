# Structure optimizer

Full source is available at [Github](https://github.com/skornel02/DISSECT-CF-Fog/tree/features/wip-structure-optimization)

## To run the code

### Frontend

1. Install required dependencies

```bash
cd ./src/frontend
yarn install
```

2. Start the frontend

```bash
yarn start
```

3. Build the frontend

```bash
yarn build
```

### Backend

1. install required dependencies

```bash
./mvnw install
```

2. Start the backend

```bash
./mvnw spring-boot:run
```
